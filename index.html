XAI for Academic Risks and Placement Success

Project Overview: This project is an advanced Academic Placement Dashboard designed to bridge the gap between academic performance and placement success. Using Machine Learning (XGBoost), the system predicts student placement probability, while Explainable AI (SHAP) provides transparent insights.

Objectives

  • To identify students at risk of underperformance early in their academic journey.
  • To provide actionable insights to faculty for personalized student intervention.
  • To maintain a transparent and interpretable prediction model for student outcomes.

Key Modules

  • Student Data Management: Centralized database for academic records and performance metrics.
  • Predictive Analytics: Implements XGBoost to classify students based on placement potential.
  • XAI Interpretability: Uses SHAP (SHapley Additive exPlanations) to explain model decisions.
  • Interactive Dashboard: Visual interface for faculty to monitor class performance.

Tech Stack

Frontend: HTML, CSS, Bootstrap | Backend: Django | ML: Scikit-learn, XGBoost, SHAP | Database: SQLite
